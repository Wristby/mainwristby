---
name: Private workspace access
description: User-approved account-provisioning boundary for this shared business application
---
Keep public registration disabled while preserving existing accounts. Do not reopen self-service registration as part of an authentication refactor.

**Why:** The user approved locking down the app after learning that public account creation could grant access to the shared business inventory and client data.

**How to apply:** Treat new-account provisioning as an explicitly authorized administrative operation, not a public sign-up flow. Ask before changing this boundary or deleting existing accounts.
